# Aplicación III Congreso Colombiano de Etnomatemática

Conserva la consulta de inscritos y añade descarga de certificados con código individual.

## Publicación
1. Descomprime el ZIP y copia **todo su contenido** en la raíz del repositorio GitHub de la app existente (incluida la carpeta `certificados/`).
2. Confirma los cambios. Streamlit Community Cloud actualizará la aplicación.
3. Entrega a cada persona **solo su código**, tomado del archivo `CODIGOS_PRIVADOS_CERTIFICADOS_2026.csv` que se entrega por separado y **NO debe subirse a GitHub**.
4. Prueba la descarga de un certificado antes de comunicarlo a los ponentes.

**Privacidad importante:** en un repositorio público de GitHub, los PDF subidos a `certificados/` pueden consultarse directamente aunque la aplicación pida código. Para restringir realmente el acceso, se necesita un almacenamiento privado y un mecanismo de autorización del lado del servidor. El código de la app controla la interfaz, no impide el acceso directo al repositorio público.

Los certificados PDF se incorporaron tal como estaban en la carpeta disponible, **sin rediseñarlos**. Revisa visualmente su contenido antes de publicarlos.
